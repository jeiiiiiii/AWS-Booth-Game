# AWS Booth Game 🎮

A fun and interactive Rock, Paper, Scissors game developed in Unity featuring AWS Cloud Club mascots! Challenge Alf, Alfina, or Alfred in this engaging booth game designed for AWS events and exhibitions.

## 🎯 Overview

AWS Booth Game is an interactive Unity-based game that brings the classic Rock, Paper, Scissors game to life with charming AWS Cloud Club mascot characters. Perfect for AWS booth demonstrations, events, and educational purposes, this game provides an entertaining way to engage with attendees while showcasing game development capabilities.

## ✨ Features

- **Three Unique Opponents**: Choose to play against:
  - **Alf** - The friendly and welcoming mascot
  - **Alfina** - The energetic and fun-loving companion
  - **Alfred** - The curious and adventurous explorer

- **Interactive Gameplay**: 
  - Classic Rock, Paper, Scissors mechanics
  - Real-time score tracking
  - Engaging dialogue system with character interactions
  - Dynamic sprite changes based on game state
  - Win/Loss animations and feedback

- **Multiple Scenes**:
  - Landing Scene - Game introduction
  - Choose Opponent Scene - Select your mascot challenger
  - Individual character scenes (Alf, Alfina, Alfred)
  - Smooth scene transitions

- **Audio Integration**: 
  - Button click sounds
  - Interactive audio feedback

## 🛠️ Built With

- **Unity Editor**: Version 6000.0.30f1
- **Universal Render Pipeline (URP)**
- **TextMesh Pro** - For enhanced text rendering
- **Unity Input System** - For modern input handling

## 📋 Requirements

- Unity 6000.0.30f1 or compatible version
- Windows/Mac/Linux operating system
- Minimum 4GB RAM
- Graphics card supporting URP

## 🚀 Getting Started

### Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/AWS-Booth-Game.git
   ```

2. **Open in Unity**:
   - Launch Unity Hub
   - Click "Add" and navigate to the cloned project folder
   - Select Unity Editor version 6000.0.30f1 (or install if not present)
   - Open the project

3. **Open the Landing Scene**:
   - Navigate to `Assets/Scenes/LandingScene.unity`
   - Press Play to test the game

## 🎮 How to Play

1. **Start the Game**: Launch from the Landing Scene
2. **Choose Your Opponent**: Select Alf, Alfina, or Alfred
3. **Play Rock, Paper, Scissors**: Click your choice
4. **Track Your Score**: Win rounds to increase your score
5. **Challenge Different Opponents**: Try playing against all three mascots!

## 🎨 Game Mechanics

- **Rock** beats Scissors
- **Scissors** beats Paper
- **Paper** beats Rock
- First to win the best of matches wins the game!
